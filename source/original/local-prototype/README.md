# Local Prototype

This folder contains the original local/prototype implementation uploaded from the coursework project.

- `Main.java` loads the RAILS and AREALM data locally and invokes both queries.
- `GeoQueryUtils.java` contains the Cartesian-product implementations of Query A and Query B.
- `MyPoint.java` is the serializable point model used by the prototype.

These files are preserved without changing their source content. They represent an earlier/local implementation and should not be confused with the grid-based experimental versions used for the reported Spark/YARN experiments.
