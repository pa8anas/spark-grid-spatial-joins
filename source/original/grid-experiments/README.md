# Grid-Based Experimental Sources

This folder contains the original Java files associated with the grid-based Spark experiments documented in the project report.

- `MainA.java` — Query A experimental implementation and earlier commented iterations.
- `MainB.java` — Query B experimental implementation and earlier commented iterations.

The files are preserved without modifying their original source content. They include multiple commented development iterations, which are kept as part of the project history.

For the exact Spark/YARN commands used during the experiments, see [`docs/experiment-commands.md`](../../../docs/experiment-commands.md).
